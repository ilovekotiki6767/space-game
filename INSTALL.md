# Building with CMake

This is currently the only way to build the game.

## Get a copy of the source:

```
git clone https://github.com/ilovekotiki6767/space-game
cd space-game
```

## Configure and build:
```
cmake -S . -B build
cmake --build build
```

## Run:
The final executable will be available in `build/Platform` (TODO ofc it will be renamed later)
